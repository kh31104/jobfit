STEP 7 기존 교수자 시험으로 돌아가기

① 교수자 로그인

INJE2026에 등록된 교수자만 실제 자료를 조회합니다. 로그인된 교수자 시험 화면에서 같은 탭으로 이동하면 세션을 유지할 수 있습니다. 조회 결과는 학생 데이터베이스에 저장하지 않습니다.

로그인 확인 중…

② 관심 산업·목표 직무에 맞는 자료 찾기

산업과 직무를 입력하면 실제 연결된 3개 원자료 중 관련 후보만 제안합니다. 일치하는 자료가 없다면 임의로 다른 산업 통계를 추천하지 않습니다. 추천 여부는 규칙 기반이며 원문 내용 확인이 필요합니다.

관심 산업을 입력한 후 ‘관련 자료 추천’을 눌러주세요.

원자료 직접 조회 (산업 관련성이 자동 보장되지는 않음)

자료는 공공데이터포털 공개 CSV에서 수신합니다. 직접 조회는 기존 교수자 시험 기능을 유지한 것입니다. 자료 기준일과 실제 조회일을 구분하며, 중기부 지원사업을 현재 접수 중인 공고로 표시하지 않습니다.

아직 자료를 조회하지 않았습니다.

③ STEP 7 산업분석 PEST 표 · 교수자 시험

조회 결과에서 빈칸에 반영을 누르면 해당 P/E/S 칸에만 복사합니다. 기존 값은 자동으로 덮어쓰지 않습니다. 직무·채용 영향은 자동 추론하지 않으며 학생이 따로 근거를 확인해야 합니다.
