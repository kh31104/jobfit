# 한국어 문체 점검 규칙

표현은 주변 문장과 장르를 보고 판단한다. 금지 단어 목록으로 일괄 치환하지 않는다.

| 점검 대상 | 편집 판단 |
| --- | --- |
| 번역투와 피동 | 누가 무엇을 했는지 원문에서 분명할 때만 능동 표현을 검토한다. 수단을 나타내는 조사나 피동이 의미에 필요하면 보존한다. |
| 영문 병기 | 독자의 이해에 필요한 약어, 공식 명칭, 정의와 인용은 유지한다. 같은 풀이가 불필요하게 반복되면 정리한다. |
| 기계적 나열 | 항목 간 차이나 순서를 보여 주지 않는 반복만 줄인다. 문항, 연구 절차, 기준 비교에 필요한 병렬 구조는 유지한다. |
| 상투 표현 | 추상적 평가를 뒷받침하는 행동이 원문에 있으면 그 행동을 드러낸다. 근거가 없으면 확인 대상으로 표시한다. |
| 문장 리듬 | 같은 종결이나 길이의 반복이 읽기 어렵게 할 때만 조정한다. 높임말과 장르의 문체를 유지한다. |
| 수식과 중복 | 동의어가 같은 역할을 하는지 확인한다. 범위나 강도를 바꾸는 수식어는 유지한다. |
| 완곡 표현 | 중복된 완곡 표현을 찾되 연구 결과의 불확실성과 지원자의 실제 확신을 유지한다. |
| 접속사 | 인과·조건·대조를 드러내는 접속사는 유지한다. 같은 관계를 겹쳐 표현할 때만 정리한다. |
| 형식명사 | 주체나 행동을 흐리는 명사화를 살핀다. 기술적 정의나 필요한 문법 구조는 유지한다. |
| 시각 장식 | 인용부호·인용 서식·표와 필요한 강조는 보호하고, 읽기를 끊는 장식만 줄인다. |

자기소개서에서는 문항이 요구한 내용을 먼저 찾고 상황, 작성자의 역할과 행동, 실제 결과의 연결을 확인한다. 논문에서는 단위·기호·인용 체계·조건·연구 한계가 원문과 일치하는지 확인한다. 직접 인용은 교정 대상에서 제외한다.
