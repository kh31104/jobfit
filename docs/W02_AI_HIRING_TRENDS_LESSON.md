# Week 2 — AI 시대의 직업·채용 트렌드와 취업전략

## Position in course
Concept + AI literacy week. No new Jobfit STEP is required; students use the Career Start baseline and prepare to use AI independently throughout the semester.

## Learning outcomes
Students can:
1. distinguish job, occupation, role and task;
2. explain why hiring is increasingly job/task/skill centered;
3. identify what generative AI does well and where human judgment remains necessary;
4. use AI for career research while checking sources and factual accuracy;
5. apply a personal AI-use rule to the semester project.

## Core messages
- 직업이 사라진다/남는다보다 업무가 어떻게 바뀌는지 본다.
- 직무명만 보지 않고 실제 Task와 Evidence를 본다.
- AI는 질문·탐색·구조화·피드백에 강하지만, 나의 경험과 의사결정을 대신하면 안 된다.
- 출처가 필요한 정보와 내 경험에서만 나올 수 있는 정보를 구분한다.

## Suggested class flow
### Block A — Changing work
Compare old vs current task bundles in several jobs.

### Block B — Changing hiring
Show the chain:
Company problem → role → task → KSA → evidence → hiring decision.

### Block C — AI career literacy
Mini-lab: Ask the same career question in a weak prompt and an evidence/source-grounded prompt, then compare outputs.

### Block D — Fact vs interpretation
Students label sample AI outputs as:
- confirmed fact;
- interpretation;
- recommendation;
- unsupported claim.

### Block E — My AI Career Rule
Students revise the Week 1 rule if needed.
Suggested frame:
“AI는 ___에 활용하되, ___은 내가 직접 판단하고, 외부 정보는 ___에서 확인한다.”

## Student output
- My AI Career Rule v2
- one example of a weak prompt rewritten into an evidence-grounded prompt
- source-check habit for later job/company research

## Bridge to Week 3
Week 3 begins Career DNA. Explain that psychological tests are one evidence source, not a job-answer generator.
