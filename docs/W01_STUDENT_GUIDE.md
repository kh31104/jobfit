# 인제대학교 Jobfit 1주차 학생 안내

## 접속 주소
`https://kh31104.github.io/jobfit/?course=INJE2026`

화면에서 다음이 보이면 정상 접속입니다.
- 인제대학교
- INJE2026
- 전체 Career Roadmap
- STEP 0 · Career Start

## 오늘 할 일 7개
1. 수업 연결 확인
2. 익명코드 생성
3. 기본정보 입력
4. 현재 진로·취업 준비상태 입력
5. AI Career Check-in
6. PRE 시작점 측정
7. 저장 + 백업

## 1. 익명코드
`익명코드 생성`을 누릅니다.

코드는 `JF26-XXXXXX` 형태입니다.
- 이름과 학번 대신 사용하는 코드입니다.
- 한 학기 동안 같은 코드를 사용합니다.
- 코드 복사 또는 개인 메모를 권장합니다.

## 2. 기본정보
실제 상태를 그대로 입력합니다.
- 나이
- 성별
- 학년
- 학과/전공계열
- 학적상태

이름, 학번, 전화번호, 정확한 생년월일은 입력하지 않습니다.

## 3. 현재 준비상태
현재 상태를 그대로 선택합니다.

`아직 시작 전`, `탐색 중`, `정하지 못함`도 정상적인 응답입니다.

## 4. AI Career Rule
예시:
> AI는 정보정리와 질문 생성에 활용하되, 경험의 사실과 최종 판단은 내가 직접 확인한다.

본인이 실제로 지킬 수 있는 원칙을 한 문장으로 적습니다.

## 5. AI LAB 00
1. `AI 인터뷰 프롬프트 만들기`
2. 프롬프트 복사
3. ChatGPT 등 사용하는 AI에 붙여넣기
4. AI 질문에 답하기
5. Jobfit에 다음 2가지만 기록
   - 지금의 나 한 문장
   - 이번 주 내가 직접 할 1가지

AI가 내가 말하지 않은 경험이나 사실을 만들면 사용하지 않습니다.

## 6. PRE 시작점 측정
### A. 고용24 구직준비도검사
검사 이름이 반드시 **구직준비도검사**인지 확인합니다.

검사 완료 후 결과표의 9개 점수를 Jobfit에 입력합니다.

### B. K-CAAS-SF 진로적응성
총 12문항입니다.

응답 기준:
- 1 = 전혀 그렇지 않다
- 5 = 매우 그렇다

모두 입력한 뒤 `PRE · 시작점 측정 한 번에 저장`을 누릅니다.

## 7. 저장 + 백업
1. `Career Start 저장`
2. `백업파일 다운로드` 또는 `공유해서 보관`
3. 가능하면 개인 이메일, 카카오톡 나에게 보내기, Google Drive, iCloud, OneDrive 등에 보관

백업파일 예시:
`jobfit-JF26-XXXXXX-2026-09-XX.json`

다른 기기에서 사용할 때는 `백업 불러오기`로 복구할 수 있습니다.
