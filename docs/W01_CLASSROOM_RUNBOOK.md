# 인제대학교 Jobfit 1주차 교수자 운영대본

## 수업 목표
학생이 120분 안에 `Career Start → AI Check-in → Work24 PRE → K-CAAS-SF PRE → 저장 → 백업`까지 완료하도록 운영한다.

## 수업 시작 전 화면
학생용 링크:
`https://kh31104.github.io/jobfit/?course=INJE2026`

학생이 첫 화면에서 확인할 것:
- 인제대학교
- INJE2026
- 전체 Career Roadmap
- STEP 0 · Career Start
- PRE/POST 측정

## 0–12분 | 왜 이 수업을 하는가
### 교수자 멘트
“이번 학기에는 매주 따로 과제를 만드는 방식이 아니라, 오늘 기록한 시작점에서 출발해서 경험·직무·기업·채용공고·지원서·면접까지 하나의 데이터로 연결합니다. 오늘은 진로를 결정하는 날이 아니라 현재 상태를 정확히 남기는 날입니다.”

### 보여줄 것
- STEP 0~13 전체 Roadmap
- 최종 AI Job Portfolio가 어떤 형태인지 짧게 예고

### 중단 기준
12분이 되면 설명을 더 하지 않고 바로 학생 실습으로 전환한다.

## 12–22분 | 접속 + 익명코드
### 교수자 멘트
“화면에 인제대학교와 INJE2026이 보이는지 먼저 확인하세요. 이름과 학번은 입력하지 않습니다. 익명코드를 생성하고 한 학기 동안 같은 코드를 사용합니다.”

### 학생 행동
1. 링크 접속
2. `익명코드 생성`
3. 코드 복사 또는 개인 메모

### 교수자 확인
- `JF26-`로 시작하는 코드 생성 여부
- 수업코드가 INJE2026인지

### 문제 발생 시
- 잘못된 일반 화면: 링크를 다시 열게 한다.
- 기존 데이터가 있는 학생: 본인 데이터인지 확인 후 진행한다.
- 다른 학생 데이터가 보이면 브라우저를 분리하거나 시크릿창 사용 후 새 코드 생성.

## 22–35분 | 기본정보 + 현재 준비상태
### 교수자 멘트
“높게 체크하는 검사가 아닙니다. ‘아직 모르겠다’, ‘탐색 중’도 정상적인 출발점입니다. 지금 상태를 그대로 체크하세요.”

### 학생 행동
- 기본정보
- 희망직무/산업 결정 정도
- 취업준비 단계
- 인턴·프로그램·지원·근로 경험
- AI 사용 시작점
- My AI Career Rule

### 교수자 순회 포인트
- 이름·학번을 임의로 적지 않는지
- 학생이 실제 상태보다 과장해 선택하지 않는지

## 35–45분 | My AI Career Rule
### 교수자 멘트
“이번 수업에서 AI는 여러분 대신 경험을 만드는 도구가 아닙니다. 질문을 만들고, 정보를 구조화하고, 비교하는 데 활용합니다. 사실 확인과 최종 판단은 본인이 합니다.”

### 권장 예시
“AI는 정보정리와 질문 생성에 활용하되, 경험의 사실과 최종 판단은 내가 직접 확인한다.”

## 45–60분 | AI LAB 00 Career Check-in
### 교수자 멘트
“AI에게 ‘나한테 맞는 직업 알려줘’라고 하지 않습니다. Jobfit이 만든 프롬프트를 복사해서 AI가 여러분에게 질문하게 하세요. 질문은 최대 5개입니다.”

### 학생 행동
1. `AI 인터뷰 프롬프트 만들기`
2. 복사
3. ChatGPT 등 외부 AI에 붙여넣기
4. 최대 5문답 진행
5. Jobfit에 두 문장만 입력
   - 지금의 나 한 문장
   - 이번 주 내가 직접 할 1가지

### 교수자 개입
AI가 학생이 말하지 않은 경력·성격을 만들어내면 삭제하도록 지도한다.

## 60–83분 | 고용24 구직준비도검사 PRE
### 교수자 멘트
“검사 이름을 반드시 확인하세요. 오늘 하는 것은 ‘구직준비도검사’입니다. S형·L형이나 대학생 진로준비도검사와 다릅니다.”

### 학생 행동
1. Jobfit의 고용24 검사 페이지 열기
2. 고용24에서 구직준비도검사 실시
3. 결과표 확인
4. Jobfit에 검사일 + 9개 점수 입력

### 9개 점수
경제적 취약성 적응도 / 가족의 지지 / 사회적 지지 / 자아 존중감 / 자기 효능감 / 구직기술 / 의사전달 / 대인관계 활용 / 구직정보 수집

### 운영 팁
- 고용24 로그인 지연 학생을 한쪽에서 별도로 지원한다.
- 먼저 끝난 학생은 K-CAAS-SF 12문항으로 넘어가게 한다.
- 로그인 문제 때문에 전체 수업을 멈추지 않는다.

## 83–93분 | K-CAAS-SF 12문항
### 교수자 멘트
“다음은 현재의 진로적응성을 보는 12문항입니다. 정답은 없습니다. 1은 전혀 그렇지 않다, 5는 매우 그렇다입니다.”

### 확인
- 12문항 전부 입력
- 1~5 범위

## 93–100분 | PRE 저장
### 교수자 멘트
“이제 `PRE · 시작점 측정 한 번에 저장`을 누르세요. 화면에 미완료 항목이 나오면 그 부분만 다시 입력합니다.”

### 교수자 확인
- Work24 9/9
- K-CAAS-SF 12/12

## 100–113분 | Career Start 저장 + JSON 백업
### 교수자 멘트
“브라우저에도 저장되지만 기기를 바꾸면 데이터가 없어질 수 있습니다. 오늘 만든 JSON 파일이 한 학기 기록의 백업입니다.”

### 학생 행동
1. `Career Start 저장`
2. `백업파일 다운로드` 또는 `공유해서 보관`
3. 개인 이메일 / 카카오톡 나에게 보내기 / Drive / iCloud / OneDrive 등에 보관 권장

### 중요
- 기기 밖 보관 확인 체크는 선택이다.
- 연구용 데이터 제출은 1주차 과제가 아니다.

## 113–120분 | Exit Ticket
### 질문
“이번 학기 Jobfit을 통해 가장 먼저 확인하거나 바꾸고 싶은 것은 무엇인가?”

### 마무리 멘트
“오늘 만든 것은 결과가 아니라 기준점입니다. 이후 수업에서는 이 기준점을 경험과 직무의 실제 근거로 바꾸겠습니다.”
