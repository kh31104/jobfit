# 9주차 — 실제 채용공고 분석 & Career Asset & Resume Lab

## 수업 위치
Jobfit STEP 7–9. 8주차에 선택한 Career FIT 방향을 실제 채용공고 하나로 검증하고, **지원자격 → 직무요구 → 내 Evidence → Resume** 순서로 실제 지원 가능성을 점검한다.

## 핵심 메시지
채용공고 분석의 목적은 키워드를 많이 뽑는 것이 아니다.

실제 공고 원문 → Application Gate → Job Requirement → Evidence 질문 → 내 경험 → Evidence 수준 → Critical GAP → Resume

순서로 연결한다.

두 가지를 반드시 구분한다.

- **Application Gate**: 졸업시점, 전공, 필수경력, 필수자격증, 필수어학, 근무조건 등 지원 가능 여부에 직접 영향을 주는 조건
- **Job Requirement**: Task, Knowledge, Skill, Attitude, Tool, Experience 등 실제 업무수행을 위해 Evidence로 증명해야 하는 요소

‘우대사항’을 필수 자격조건처럼 해석하지 않는다.

## 학습목표
학생은 수업 후 다음을 할 수 있다.
1. 실제 채용공고에서 지원자격 Gate와 직무 Requirement를 분리할 수 있다.
2. 졸업·전공·경력·필수자격 등 Hard Gate의 충족/충족가능/미충족/확인필요 상태를 판단할 수 있다.
3. Job Requirement를 Task, Knowledge, Skill, Attitude, Tool, Experience, Qualification, Preferred로 분해할 수 있다.
4. 공고에 명시된 내용과 AI 해석을 구분할 수 있다.
5. 각 Requirement의 원문 근거와 Evidence 질문을 기록할 수 있다.
6. Requirement별 자신의 경험 Evidence를 A/B/C/없음으로 구분할 수 있다.
7. 핵심·필수 Requirement의 C/없음 Evidence를 Critical GAP로 식별할 수 있다.
8. 검증된 Career Asset만 최종 Resume Bullet로 사용할 수 있다.

# STEP 7 — JD Analyzer

## 1. 실제 공고 등록
필수:
- 기업명
- 공고명
- 지원직무
- 공고 출처
- URL
- 확인일
- 마감일
- 공고 원문

가능하면 8주차 우선방향의 Company / Job을 이어서 사용한다.

## 2. Application Gate
먼저 지원 가능 여부에 영향을 주는 조건만 분리한다.

예:
- 2027년 2월 졸업예정자
- 전기·전자 관련 전공
- 전기기사 필수
- 경력 2년 이상
- 특정 근무지 근무 가능자

각 Gate에 기록:
- 조건 원문
- 구분
- 공고 근거문구
- 나의 현재 상태
  - 충족
  - 충족 가능
  - 미충족
  - 확인 필요
  - 해당 없음
- 필요한 다음 행동

### 해석원칙
미충족 Gate가 있다고 해서 AI가 임의로 “지원 가능”이라고 해석하지 않는다.

다만 실제 기업의 인정기준·예외조건이 별도로 있을 수 있으므로 지원 전 공식 공고·FAQ·채용문의 등을 직접 확인한다.

## 3. Requirement Evidence Table
Application Gate를 제외한 업무 요구를 하나씩 분리한다.

각 Requirement:
- 요구사항
- Type
  - Task
  - Knowledge
  - Skill
  - Attitude
  - Tool
  - Experience
  - Qualification
  - Preferred
- 중요도
  - 업무핵심
  - 필수
  - 우대
  - 참고
- 명시 수준
  - 공고에 명시
  - 문맥에서 확인
  - 추가 확인 필요
- 공고 근거 문구
- 행동·역량 신호
- Evidence 질문
- Unknown

## Evidence 질문의 의미
공고 Requirement:
> 생산 데이터를 분석하여 공정 개선

단순 해석:
> 데이터분석 역량 필요

보다 다음 질문이 중요하다.

- 실제 데이터를 정리·분석해 문제원인을 찾은 경험이 있는가?
- 어떤 데이터를 사용했고 본인이 직접 한 분석은 무엇인가?
- 분석 결과가 실제 의사결정이나 개선으로 이어졌는가?
- 결과를 무엇으로 확인할 수 있는가?

이 질문이 STEP 8과 면접에서 다시 사용된다.

## Job Deep Dive vs 실제 JD
STEP 4는 ‘일반적으로 이 직무가 무엇을 하는가’를 여러 자료로 확인한다.

STEP 7은 ‘이 기업이 이번 채용에서 실제로 무엇을 요구하는가’를 본다.

둘이 다르면:
- 이번 지원에서는 JD를 우선
- 공고 하나를 직무 전체의 정의로 일반화하지 않음
- 차이가 큰 이유를 산업·기업맥락에서 다시 확인

# STEP 8 — Career Asset Match

## Evidence 수준
- **A · 직접 증거**: Requirement와 직접 연결되는 행동과 결과가 있음
- **B · 관련 증거**: 유사한 행동·상황 Evidence가 있음
- **C · 간접 증거**: 과목·간접경험 등 제한된 근거
- **없음**: 현재 증명 가능한 Evidence 없음

‘없음’은 실패가 아니라 GAP 데이터다.

## Critical GAP
모든 Requirement를 똑같이 취급하지 않는다.

특히 다음을 먼저 본다.
- 중요도 = 업무핵심 또는 필수
- Evidence = C 또는 없음

이 조합은 Jobfit에서 **Critical GAP**으로 표시한다.

또한 STEP 7의 Application Gate가 미충족/확인필요이면 Career Asset이 많더라도 별도 경고를 유지한다.

교수자 질문:
- 이 GAP는 지원 전 해결 가능한가?
- 이번 공고에서는 포기해야 할 조건인가?
- 다른 공고에서는 필수가 아닐 수 있는가?
- 단기간 학습·프로젝트로 Evidence를 보완할 수 있는가?

## Career Asset 필수요소
- 경험명
- 연결 Requirement
- Requirement 중요도
- 내가 직접 한 핵심행동
- 사실 Evidence
- 직무 연결 논리
- Evidence 수준
- 남는 GAP
- 원경험 Fact Check
- Career Asset Fact Check
- 활용처

# STEP 9 — Resume Lab

## Resume Evidence Gate
Resume에는 Evidence ‘없음’ 자산을 사용하지 않는다.

A/B/C 자산도 바로 최종문장이 되는 것은 아니다.

최종 사용 조건:
1. 원경험 Fact Check 완료
2. Career Asset Fact Check = 검증완료
3. Resume 문장 Fact Check 완료

세 단계가 충족돼야 Jobfit에서 **Final Ready**로 본다.

검증이 끝나지 않은 자산도 수업 중 초안 작성은 가능하지만 **Draft**로만 저장한다.

## Resume Bullet 기본 구조
**Action + 대상/방법 + Result/Evidence**

예:
> 8개 실험조건의 측정값을 비교해 센서 오차 원인을 구분하고 회로 수정안을 도출

실제 수치가 없다면 숫자를 만들지 않는다.

## 작성 순서
1. 학생이 사실 중심 원문 작성
2. AI가 문장 구조·간결성 제안
3. Career Asset과 원경험 대조
4. 최종 Bullet 수정
5. Resume Fact Check
6. Final Ready 또는 Draft 구분

AI 초안을 바로 최종문장으로 사용하지 않는다.

# 120분 운영안

### 0–12분 | 실제 JD 선택
8주차 우선방향을 기준으로 실제 채용공고 1건 등록.

### 12–27분 | Application Gate 분리
졸업·전공·경력·필수자격 등 지원자격 조건을 먼저 확인한다.

학생은 각 조건을 충족/충족가능/미충족/확인필요로 판단한다.

### 27–45분 | AI JD 구조화
Jobfit 프롬프트를 외부 AI에서 실행한다.

AI가 Gate와 Requirement를 섞었는지, 공고 원문 밖의 일반론을 넣었는지 확인한다.

### 45–62분 | Requirement Evidence Table
핵심 Requirement 최소 5개 권장.
각 항목에 원문 근거와 Evidence 질문 작성.

### 62–72분 | JD 핵심해석
이 공고가 중요하게 보는 3가지와 Unknown을 정리.

### 72–95분 | Career Asset Match
핵심 Requirement마다 실제 경험을 연결하고 A/B/C/없음 판단.

### 95–105분 | Critical GAP 확인
- Hard Gate 미충족/확인필요
- 핵심·필수 Requirement의 C/없음

을 구분한다.

### 105–117분 | Resume Bullet 작성
Career Asset 1~3개를 이력서/경험기술서 문장으로 변환.
검증 미완료 자산은 Draft로 저장한다.

### 117–120분 | 다음주 연결
> 다음 시간에는 검증된 Evidence를 자기소개서 문항의 평가의도와 연결합니다. 없는 경험을 만드는 것이 아니라 어떤 Evidence를 어떤 질문에 배치할지를 결정합니다.

# AI 사용 규칙
AI는:
- 공고 구조화
- Application Gate와 Requirement 분리
- Requirement 분류
- Evidence 질문 생성
- 사실 기반 문장 간결화

에 사용한다.

AI는:
- 공고에 없는 지원자격 추가
- 우대를 필수조건으로 변경
- 경험 생성
- 수치·성과 발명
- Evidence 없음 경험을 그럴듯하게 연결

해서는 안 된다.
