# Week 9 — 실제 채용공고 분석 & 이력서·경험기술서

## Position in course
Jobfit STEP 7–9. The midterm career hypothesis is tested against a real recruitment posting.

## Learning outcomes
Students can:
1. separate a real JD into Task, qualifications, preferred conditions, KSA, tools and experience signals;
2. distinguish explicit requirements from interpretation;
3. match JD requirements with Career Assets;
4. identify evidence gaps before writing;
5. write factual, action-centered resume bullets and experience descriptions.

## Class flow
### Block A — Choose one real JD
Students select an actual company/job posting they could realistically consider. Save company, job, source, URL, closing date and posting text in STEP 7.

### Block B — JD Analyzer
Use the Jobfit prompt to structure only the pasted posting. Students manually confirm requirements and add them one by one.

### Block C — Career Asset Match
For each key requirement:
- select one real experience;
- identify direct action;
- record factual evidence;
- record gaps;
- decide evidence strength.

### Block D — Resume Lab
Transform strong Career Assets into:
- one-line resume bullets;
- 3–5 sentence experience descriptions where needed.

## AI use rule
AI may structure a real posting and improve sentence economy. It may not invent achievements, numbers, responsibilities or tools.

## Student outputs
- Target JD
- JD Requirement list
- Requirement × Career Asset matches
- job-targeted resume bullets
- experience description draft

## Instructor checkpoints
- Ask students to show where each requirement appears in the posting.
- Remove generic skills that are not supported by the posting or student evidence.
- Check that resume claims can be defended in an interview.
