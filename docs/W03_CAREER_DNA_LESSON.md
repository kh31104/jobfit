# 3주차 — Career DNA: 내가 생각하는 나와 검사에서 나타난 나

## 수업 위치
Jobfit STEP 1. 자기인식 자료와 공식검사 결과를 비교해 `Career DNA 가설 v1`을 만든다.

## 핵심 질문
- 나는 어떤 활동에 자연스럽게 끌리는가?
- 일을 선택할 때 무엇을 중요하게 생각하는가?
- 내가 스스로 생각하는 강점은 무엇인가?
- 공식검사에서는 어떤 흥미·가치·성격강점 단서가 나타나는가?
- 자기인식과 검사결과가 일치하는 부분과 예상 밖인 부분은 무엇인가?
- 다음 주 실제 경험으로 무엇을 확인해야 하는가?

## STEP 1 화면 흐름
1. 커리어 밸런스게임 — 수업용 워밍업. 심리검사가 아님
2. 내가 생각하는 나의 흥미 — 검사 전 자기인식 기록
3. 고용24 직업선호도검사 S형 — 공식 외부검사 후 RIASEC 결과 입력
4. 내가 생각하는 나의 직업가치 — 검사 전 자기인식 기록
5. 고용24 성인용 직업가치관검사 — 공식 외부검사 후 결과 입력
6. 내가 생각하는 나의 강점 — VIA 결과 전 대표 강점 5개 선택
7. VIA 성격강점 — 공식 VIA 결과의 TOP5만 입력
8. 내가 생각하는 나 × 검사에서 나타난 나 — 일치·연결·예상 밖·확인 필요를 직접 비교
9. AI 자기이해 통합분석 — 현재 입력된 자료만 사용해 자기이해 가설 생성
10. Career DNA 가설 v1 — 학생이 결과를 검토하고 수정한 뒤 저장

## 설계 원칙
- 커리어 밸런스게임은 심리검사가 아니라 워밍업·가치 언어화 활동이다. AI 통합분석의 핵심 검사근거로 사용하지 않는다.
- 고용24 직업선호도검사 S형과 성인용 직업가치관검사는 고용24에서 직접 실시하고 Jobfit에는 결과만 입력한다.
- VIA 문항을 Jobfit에 복제하지 않는다. 공식 외부검사 결과의 TOP5만 교육용 보조자료로 사용한다.
- Career Anchor 40문항과 다중지능검사는 연구용 Career DNA 표준구성에서 제외한다.
- 검사가 ‘실제 나’, 자기인식이 ‘틀린 나’라는 식으로 구분하지 않는다.
- 검사결과 하나만으로 직무역량·적합직업·확정강점을 판단하지 않는다.
- 서로 다른 자료에서 비슷한 특징이 나타나도 STEP 1에서는 `반복 단서`로만 표현한다.
- `행동 근거`라는 표현은 STEP 2 실제 경험에서 행동·결과·증거가 확인된 뒤에만 사용한다.
- 입력하지 않은 검사결과나 특성을 AI가 추정하지 않는다.
- Career DNA는 고정적인 개인 유형이 아니라 현재 시점의 자기이해 가설이다.

## 학생 산출물
**Career DNA 가설 v1**
- 현재 중요하게 생각하는 일의 조건
- 여러 자료에서 반복해서 나타난 단서
- 흥미·가치·강점에서 연결되는 부분
- 자기인식과 검사결과가 다른 부분 또는 예상 밖인 부분
- 아직 확인이 필요한 부분
- STEP 2 실제 경험에서 확인할 질문

## 4주차 연결
3주차의 결과는 결론이 아니라 가설이다.

다음 시간에는 검사점수를 더 해석하기보다 실제 경험에서 다음을 확인한다.
- 무엇을 했는지
- 왜 그렇게 행동했는지
- 어떤 결과가 있었는지
- 어떤 증거가 남아 있는지
- 반복해서 확인되는 행동 특성과 역량 후보가 무엇인지

`Career DNA 가설 v1 → 실제 경험 → 행동·결과·증거 → Experience Map`으로 연결한다.

## 이번 학기 운영
- 이번 학기에는 연구용 데이터를 자동 제출하지 않는다.
- 개인 검사결과와 활동내용은 별도 연구동의 없이 연구 DB로 전송하지 않는다.
- 학생 자료는 본인 브라우저와 개인 JSON 백업으로 이어간다.
- 연구 참여 여부는 수업 참여·성적·피드백에 영향을 주지 않는다.
