# 3주차 — Career DNA: 내가 생각하는 나와 검사에서 나타난 나

## 수업 위치
Jobfit STEP 1. 여러 자기이해 자료를 비교해 `Career DNA 가설 v1`을 만든다.

## 핵심 질문
- 나는 일을 선택할 때 무엇을 중요하게 생각하는가?
- 내가 스스로 생각하는 강점은 무엇인가?
- 검사에서는 어떤 강점·커리어 기준·활동방식이 나타나는가?
- 여러 자료에서 반복되는 부분과 예상과 다른 부분은 무엇인가?
- 다음 주 실제 경험으로 무엇을 확인해야 하는가?

## STEP 1 화면 흐름
1. Balance Game — 선택 상황에서 나타난 가치·선호 단서
2. Career Anchor — 커리어 기준과 선호를 8개 앵커 점수로 확인
3. 내가 생각하는 나의 강점 — VIA 결과를 보기 전에 대표 강점 5개 선택
4. VIA 성격강점 — TOP5 입력
5. 다중지능검사 — TOP3 입력, 선호 활동·문제해결 방식의 참고자료로 사용
6. 내가 생각하는 나 × 검사에서 나타난 나 — 반복·연결·예상 밖·확인 필요를 학생이 직접 비교
7. AI 통합분석 — 현재 입력된 자료만 사용해 한 번에 자기이해 가설 생성
8. Career DNA 가설 v1 — 학생이 결과를 검토하고 자기평가 후 저장

## 설계 원칙
- 별도의 RIASEC 흥미검사나 Big Five 성격검사를 추가하지 않는다.
- Balance Game은 심리검사가 아니라 선택 상황에서 나타난 가치·선호 단서다.
- Career Anchor, VIA, 다중지능 결과를 직업의 정답으로 사용하지 않는다.
- VIA는 성격강점 자기보고 자료이며 직무역량 판정도구가 아니다.
- 다중지능 결과는 객관적 능력의 확정판정이 아니라 활동·문제해결 방식의 참고자료다.
- 검사가 ‘실제 나’, 자기인식이 ‘틀린 나’라는 식으로 구분하지 않는다.
- 입력하지 않은 검사결과나 특성을 AI가 추정하지 않는다.
- 3주차에는 Career DNA 인터뷰를 하지 않는다.
- 3주차 AI는 현재 자료를 통합해 가설과 4주차 확인질문을 만드는 역할만 한다.

## 학생 산출물
**Career DNA 가설 v1**
- 내가 중요하게 생각하는 일의 조건
- 반복해서 나타난 강점 후보
- 선호하는 활동·문제해결 방식
- 자기인식과 검사결과가 연결되는 부분
- 예상과 달랐던 부분
- 아직 확인이 필요한 부분
- 4주차 실제 경험으로 확인할 질문

## 4주차 연결
3주차의 결과는 결론이 아니라 가설이다.

다음 시간에는 검사결과를 더 해석하지 않고 실제 경험에서:
- 내가 무엇을 했는지
- 왜 그렇게 행동했는지
- 어떤 결과와 증거가 있는지
- 그 행동에서 어떤 강점·역량을 확인할 수 있는지

를 찾는다.

`Career DNA 가설 v1 → 실제 경험 → Experience Map`으로 연결한다.

## 이번 학기 운영
- 이번 학기에는 연구용 데이터를 수집하지 않는다.
- 개인 검사결과와 활동내용은 교수자 연구 DB로 자동 전송하지 않는다.
- 학생 자료는 본인 브라우저와 개인 JSON 백업으로 이어간다.
