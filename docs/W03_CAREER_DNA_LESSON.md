# 3주차 — Career DNA: 내가 생각하는 나와 검사에서 나타난 나

## 수업 위치
Jobfit STEP 1. 자기인식 자료와 공식 검사결과를 비교해 `Career DNA 가설 v1`을 만든다.

## 핵심 질문
- 나는 어떤 활동에 자연스럽게 관심이 가는가?
- 나는 직업과 회사를 선택할 때 무엇을 중요하게 생각하는가?
- 내가 스스로 생각하는 강점은 무엇인가?
- 고용24와 VIA 결과에서는 어떤 단서가 나타나는가?
- 자기인식과 검사결과에서 반복되거나 예상과 다른 부분은 무엇인가?
- 다음 STEP의 실제 경험에서 무엇을 확인해야 하는가?

## STEP 1 화면 흐름
1. 커리어 밸런스게임 — 심리검사가 아닌 워밍업
2. 내가 생각하는 나의 흥미 — 검사 전 자기인식 기록
3. 고용24 직업선호도검사 S형 — RIASEC 결과점수 입력
4. 내가 생각하는 나의 직업가치 — 검사 전 자기인식 기록
5. 고용24 성인용 직업가치관검사 — 9개 가치점수 입력
6. 내가 생각하는 나의 강점 — VIA 결과 전 대표 강점 5개 선택
7. VIA 성격강점 TOP5 — 공식 외부검사 결과의 보조 자기이해 자료
8. 내가 생각하는 나 × 검사에서 나타난 나 — 반복 단서·연결·예상 밖·확인 필요를 학생이 직접 비교
9. AI 자기이해 통합분석 — 현재 입력된 자료만 사용해 자기이해 가설 생성
10. Career DNA 가설 v1 — 학생이 결과를 검토하고 자기평가 후 저장

## 설계 원칙
- 밸런스게임은 심리검사가 아니며 AI 통합분석의 핵심 근거로 사용하지 않는다.
- 흥미와 직업가치는 공식 검사결과를 보기 전에 학생의 자기인식을 먼저 기록한다.
- 고용24 검사는 공식 사이트에서 실시하고 Jobfit에는 결과점수와 검사일만 입력한다. 검사문항을 Jobfit 내부에 복제하지 않는다.
- VIA는 성격강점에 관한 보조 자기이해 자료이며 직무역량·채용적합성·고정된 성격유형 판정도구로 사용하지 않는다.
- Career Anchor 40문항과 다중지능검사는 연구용 Career DNA 표준구성에서 제외한다.
- 검사가 ‘실제 나’, 자기인식이 ‘틀린 나’라는 식으로 구분하지 않는다.
- 서로 다른 자료에서 비슷한 특징이 나타나더라도 STEP 1에서는 ‘반복 단서’라고 표현한다.
- 실제 경험의 행동·판단·결과·증거가 확인된 뒤에만 ‘행동 근거’로 해석한다.
- 입력하지 않은 검사결과나 특성을 AI가 추정하지 않는다.
- AI는 직업을 추천하거나 강점·약점·직무역량을 확정하지 않고 가설과 확인질문을 만드는 역할만 한다.

## 학생 산출물
**Career DNA 가설 v1**
- 현재 중요하게 생각하는 일의 조건
- 반복해서 나타난 자기이해 단서
- 흥미와 강점에서 탐색해볼 활동 방식
- 자기인식과 검사결과가 연결되는 부분
- 예상과 달랐던 부분
- 아직 확인이 필요한 부분
- STEP 2 실제 경험에서 확인할 질문

## 다음 STEP 연결
STEP 1 결과는 결론이 아니라 가설이다.

다음 STEP에서는:
- 내가 실제로 무엇을 했는지
- 왜 그렇게 판단하고 행동했는지
- 어떤 결과가 있었는지
- 확인 가능한 증거가 무엇인지
- 어떤 강점·역량 후보가 행동으로 뒷받침되는지

를 확인한다.

`Career DNA 가설 v1 → 실제 경험 → 행동 근거 → Experience Map`으로 연결한다.

## 데이터 원칙
- 자기인식 자유서술과 AI 분석 전체 원문은 연구 Core에 자동 저장하지 않는다.
- 고용24 검사명·검사일·하위점수와 같은 구조화 결과는 승인된 수집범위 안에서만 저장한다.
- VIA TOP5는 기본적으로 교육용 보조자료이며 필수 연구변수로 두지 않는다.
- Career Anchor·다중지능의 기존 데이터는 legacy로 구분하고 신규 연구용 데이터로 자동 변환하지 않는다.
