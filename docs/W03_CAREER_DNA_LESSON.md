# 3주차 — Career DNA: 흥미·성격·가치·강점 통합분석

## 수업 위치
Jobfit STEP 1. 자기이해 검사를 한 주에 통합하되, 검사결과를 직무의 정답으로 사용하지 않는다.

## 핵심 학습목표
학생은 수업 후 다음을 할 수 있다.
1. 고용24 직업선호도 S형(개정) 또는 L형(개정) 중 하나의 결과를 정확히 읽고 입력한다.
2. RIASEC 6개 원점수·표준점수를 직업명보다 흥미 패턴으로 해석한다.
3. L형 응시자는 성격 5요인·세부 성격·생활사 결과를 흥미와 구분한다.
4. 성인용 직업가치관검사의 9개 가치 결과를 읽는다.
5. VIA TOP5를 교육용 보조자료로 사용한다.
6. 검사결과와 실제 자기경험의 일치·의문·불일치를 구분한다.
7. AI를 추천엔진이 아니라 질문자로 사용한다.

## 고용24 현재 운영 기준
- 직업선호도검사 S형(개정): 흥미 중심, 약 25분
- 직업선호도검사 L형(개정): 흥미 + 성격 + 생활사, 약 60분
- 성인용 직업가치관검사: 가치, 약 20분
- 한 학생은 S 또는 L 하나만 시행
- L형 지정 수업은 사전검사 완료를 권장

## Jobfit 입력 구조
### S형
- 검사일
- 결과표 명칭/버전
- R/I/A/S/E/C 원점수 6개
- R/I/A/S/E/C 표준점수 6개
- 고용24 결과표 추천직업: 선택 입력, 참고용만 저장

### L형
S형 입력값 +
- 성격 5요인
- 결과표에 있는 경우 타당도 관련 점수
- 성격 하위요인
- 생활사 특성

### 직업가치관
현재 고용24 안내 기준 9개 가치:
- 사회적 공헌
- 변화 지향성
- 성취
- 경제적 보상
- 자기개발
- 일과 삶의 균형
- 사회적 인정
- 자율성
- 직업안정성

## 가장 중요한 설계 원칙
고용24 결과표의 추천직업이나 RIASEC TOP 유형을 STEP 3 직무후보에 자동 투입하지 않는다.

검사결과 → 직무추천이 아니라,

검사결과 → 자기검증 → 실제 경험 확인 → 다양한 직무탐색 → 공식자료 검증 → 학생 직접선택

순서로 진행한다.

## 120분 수업 흐름
### 0–10분 | 검사결과의 올바른 역할
교수자 메시지:
> 오늘의 목표는 검사로 직업을 결정하는 것이 아니라, 나를 설명하는 가설을 만들고 실제 경험으로 확인하는 것입니다.

### 10–25분 | RIASEC 전체 패턴 읽기
- TOP1·TOP2만 보지 않기
- 6개 전체 분포 비교
- 흥미 ≠ 능력
- 흥미 ≠ 취업성공 가능성

### 25–50분 | Jobfit에 S/L 결과 입력
- 결과표와 숫자 대조
- 검사일·버전 기록
- L형 학생은 성격 5요인 입력
- 결과표 추천직업은 필요한 경우 참고용으로만 기록

### 50–70분 | 직업가치관 입력·해석
- 9개 전체 점수 입력
- TOP3 확인
- 실제 선택 경험과 연결

### 70–80분 | VIA TOP5
- 교육용 보조자료
- 강점명을 경험 증거로 착각하지 않기

### 80–100분 | 결과와 실제 나 비교
Jobfit 세 영역:
1. 일치하는 결과
2. 확인이 필요한 결과
3. 동의하기 어려운 결과

각 판단마다 실제 경험을 한 가지 이상 떠올린다.

### 100–115분 | AI LAB — Career DNA Interview
AI 규칙:
- 검사점수만으로 직무명 추천 금지
- 결과 간 공통점/충돌점 구분
- 실제 경험을 확인하는 질문 생성
- 학생이 말하지 않은 경험·성격·역량 생성 금지

### 115–120분 | 결과표 대조 체크 + 저장
학생은 Jobfit의 '결과표 대조 완료'에 체크한 뒤 저장한다.

## 학생 산출물
**Career DNA Profile**
- S 또는 L 검사유형
- RIASEC 전체점수
- L형 성격결과(해당자)
- 직업가치 전체점수 및 TOP3
- VIA TOP5
- 일치/의문/불일치 자기검증
- 결과표 대조여부

## 4주차 연결
> 다음 시간부터는 검사결과보다 실제 경험에서 내가 무엇을 했는지를 더 중요하게 봅니다.

## 공식자료 기준
- 고용24 직업심리검사 실시 목록
- 고용24 OPEN-API 심리검사결과 명세
- 고용24는 직업선호도검사를 개인의 능력·학력·전공·가치관까지 포함한 종합 직업결정 도구로 보지 않으며, 다른 개인정보와 함께 종합적으로 탐색하도록 안내한다.
