# 6주차 — Job Explorer & Job Deep Dive

## 수업 위치
Jobfit STEP 3–4. 3주차 Career DNA와 4주차 Experience Map을 바탕으로 직무 후보를 넓게 탐색하고, 선택 직무의 실제 Task·KSA·KPI를 공식자료로 검증한 뒤 내 경험근거와 매칭한다.

## 핵심 질문
- 내가 가진 강점·역량은 어떤 실제 업무에서 사용될 수 있는가?
- 그 업무를 수행하는 직무 후보는 무엇인가?
- 그 직무의 실제 Task는 무엇인가?
- 어떤 KSA와 Tool이 필요한가?
- 성과는 어떤 KPI·성과기준으로 판단되는가?
- 4주차 Experience Map의 어떤 경험이 직접 근거가 되는가?
- 어떤 부분은 GAP으로 남는가?

## 핵심 원칙
검사결과 → 자동 직무추천 X

`Career DNA + Experience Map → 다양한 직무 후보 → 공식 직무정보 확인 → Target Job 직접 선택 → Task·KSA·KPI × My Evidence 매칭`

직무 적합도나 취업성공확률을 계산하지 않는다.

## STEP 3 — Job Explorer

### 01. 나의 직무탐색 근거 확인
3주차와 4주차 자료를 세 묶음으로 본다.
- 강점 단서: 내가 선택한 강점, VIA
- 가치·커리어 기준: Balance Game, Career Anchor
- 경험에서 확인한 역량: Experience Map의 행동·결과·역량·근거행동

특정 검사 하나만으로 직무를 정하지 않는다.

### 02. AI 직무탐색
AI에게 “나에게 맞는 직무 3개 추천해줘”라고 하지 않는다.

요청 기준:
- 가능하면 후보 8~12개
- 최소 4개 이상의 서로 다른 직무군
- 내 강점·경험 행동과 연결되는 대표 Task 가설
- 왜 더 탐색할 가치가 있는지
- 실제 자료에서 무엇을 확인해야 하는지
- 출처를 확인하지 않았다면 URL이나 근거를 만들어내지 않기

### 03. 직무 후보 Pool
학생은 AI 결과를 그대로 저장하지 않는다.

후보별 기록:
- 직무명 / 직무군
- 실제 자료에서 확인한 대표 Task
- 내 강점·관심과의 연결
- Experience Map의 행동근거
- 더 확인할 Task·KSA·KPI
- 공식자료 출처 / URL
- 업무 관심 / 경험근거 / 가치 / 정보확인 수준

권장:
- 후보 8~12개
- 최소 4개 직무군
- 같은 직무군만 반복되면 재탐색

### 04. Target Job 1·2·3 선택
학생이 최대 3개를 직접 선택한다.

선택 기준:
- 실제 업무가 궁금한가?
- 내 경험에서 연결할 근거가 있는가?
- 가치관과 크게 충돌하지 않는가?
- 실제 자료를 충분히 확인했는가?

선택된 직무는 STEP 4에서 깊게 분석한다.

## STEP 4 — Job Deep Dive

### 1. Source Register
직무별 최소 2개 이상의 근거를 등록한다.

권장 출처:
- 기업 공식 직무소개
- 기업 공식 채용공고
- NCS
- 고용24 직업정보
- 공공기관·정부자료
- 산업협회·전문기관

AI 답변 자체는 출처로 인정하지 않는다.

### 2. Task Evidence Map
실제 Task를 하나씩 등록한다.

각 Task:
- Task명
- 근거 출처
- 중요도
- 주요 산출물·결과
- 업무맥락·협업대상

### 3. 직무 핵심 구조
- KSA
- KPI·성과기준
- Tool·시스템·방법
- 신입 진입경로·선호경험
- 업무환경·협업대상
- 기업·산업에 따라 달라질 수 있는 부분

자료에서 확인되지 않은 KPI나 자격요건을 AI가 임의로 보완하지 않는다.

### 4. Requirement × My Evidence Matrix
4주차 Experience Map을 근거로 비교한다.

요구사항별로:
- Task / Knowledge / Skill / Attitude / Tool / Experience / Qualification
- 중요도
- Evidence 수준
  - A: 직접 증거
  - B: 관련 증거
  - C: 간접 증거
  - 없음
- 내 실제 Experience Map 근거
- 현재 GAP

키워드가 같다는 이유만으로 매칭하지 않는다.

예를 들어 ‘분석력’이라고 저장되어 있어도:
- 어떤 데이터를 봤는가
- 무엇을 비교했는가
- 어떤 판단을 했는가
- 결과가 어떻게 달라졌는가

가 확인되어야 강한 Evidence로 본다.

## 120분 운영안
### 0–15분 | Experience Map 다시 보기
4주차에서 저장한 강점·역량·행동근거를 확인한다.

### 15–35분 | AI로 직무 후보 확장
후보 8~12개, 서로 다른 업무군을 탐색한다.

### 35–55분 | 공식자료로 대표 Task 확인
NCS·고용24·기업 공식 직무소개·채용공고 중 하나 이상을 확인한 후보만 Jobfit에 저장한다.

### 55–70분 | Target Job 1·2·3 선택
학생이 직접 선택한다.

### 70–90분 | Source Register + Task Evidence Map
우선 직무 1개를 중심으로 출처와 실제 Task를 정리한다.

### 90–105분 | KSA·KPI·Tool 정리
성과기준과 요구역량을 확인한다.

### 105–115분 | Requirement × My Evidence
직무 요구와 4주차 Experience Map의 경험을 매칭한다.

### 115–120분 | 직무분석 결론
- 내 강점 Evidence
- 가장 큰 GAP
- 7주차 산업·기업에서 더 확인할 점

## 학생 산출물
**Target Job 1·2·3 + Evidence-based Job Analysis**
- 다양한 직무 후보 Pool
- Target Job 최대 3개
- Source Register
- Task Evidence Map
- KSA/KPI/Tool/업무맥락
- Requirement × My Evidence Matrix
- 강한 Evidence와 GAP

## 7주차 연결
같은 직무라도 산업과 기업이 달라지면 고객·제품·Task·Tool·KPI·업무환경이 달라질 수 있다.

6주차에 선택한 직무를 기준으로 7주차에는:
- 관심사 → 산업
- 가치관 → 기업

을 연결해 실제 취업목표를 구체화한다.
