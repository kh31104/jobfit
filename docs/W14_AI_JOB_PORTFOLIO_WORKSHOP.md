# 14주차 — AI Job Application Portfolio Workshop

## 수업 위치
Jobfit STEP 13. 학생은 한 학기 동안 검증한 결과를 하나의 실제 지원 패키지로 조립한다.

## 핵심 메시지
14주차는 새 자료를 처음부터 만드는 시간이 아니다.

**검증된 자료를 불러오기 → Draft와 Final Ready 구분 → Critical GAP 확인 → 필요한 것만 선택 → 편집 → PDF/제출본 완성**

과정이다.

## 학습목표
학생은 수업 후 다음을 할 수 있다.
1. Jobfit 누적 데이터를 빈 문서에서 다시 만들지 않고 조립할 수 있다.
2. Application Gate 상태를 최종 확인할 수 있다.
3. 하나의 Target JD에 관련된 Evidence만 선택할 수 있다.
4. Final Ready와 Draft 자료를 구분할 수 있다.
5. Career Asset → Resume → Cover Letter → Interview의 Evidence Chain을 설명할 수 있다.
6. Critical GAP를 숨기지 않고 보완계획으로 연결할 수 있다.
7. 30일·90일 Action Plan을 작성할 수 있다.
8. 실제 지원에 사용할 PDF/최종본을 만들 수 있다.

## Portfolio Readiness Dashboard
STEP 13은 자동으로 다음을 보여준다.
- Application Gate
- Verified Career Asset 수
- Final Ready Resume 수
- Final Ready Cover Letter 수
- Ready Interview Evidence 수
- 핵심·필수 Critical GAP 수

이 수치는 합격확률이나 종합점수가 아니다.

## Portfolio 구조
1. **WHO I AM** — Career DNA + Evidence 기반 역량
2. **TARGET JOB** — Target Job
3. **INDUSTRY & COMPANY** — 목표 산업·기업
4. **TARGET JD & APPLICATION GATE** — 실제 채용공고 + 지원자격 확인
5. **VERIFIED CAREER ASSETS** — 검증된 경험 Evidence
6. **RESUME · FINAL READY** — 검증 완료 Bullet
7. **COVER LETTER · HUMAN-FIRST** — 최종 자기소개서
8. **INTERVIEW EVIDENCE · READY** — 실제 답변근거
9. **CAREER FIT** — 현재 직무·산업·기업 우선방향과 판단근거
10. **CRITICAL GAP & ACTION PLAN** — JD GAP + 30/90일 계획

## 중요한 출력 원칙
Draft는 자동으로 최종 지원자료에 섞지 않는다.

예:
- 검증되지 않은 Resume Bullet → Portfolio 최종 Resume에서 제외
- Draft Cover Letter → Human-First Final Ready 문항보다 우선하지 않음
- Fact Check 미완료 Interview → Ready Interview Evidence에서 제외

학생은 ‘왜 빠졌는지’를 Dashboard에서 확인하고 필요한 경우 앞 STEP으로 돌아가 수정한다.

## 120분 Workshop 운영안
### 0–15분 | Portfolio Readiness
전체 Dashboard 확인.

각 학생은 먼저 세 가지를 표시한다.
- 지금 바로 사용 가능
- 오늘 수정하면 사용 가능
- 이번 지원에서는 GAP

### 15–30분 | Target JD 재확인
기업·직무·공고 URL, 마감일, Application Gate를 다시 확인한다.

### 30–50분 | Career Asset Selection
Target JD에 실제로 필요한 Verified Career Asset만 남긴다.

### 50–70분 | Resume + Cover Letter
Final Ready 문장 확인, 중복메시지 제거, 핵심 Evidence 순서 조정.

### 70–85분 | Interview Evidence
지원서에서 가장 검증가능성이 높은 질문과 답변근거 확인.

### 85–100분 | Positioning + Critical GAP
한 문장 Positioning 작성.

Critical GAP는 삭제하지 않는다. 실제 지원 전 보완할 것인지, 이번 공고에서는 감수할 것인지 판단한다.

### 100–110분 | 30/90 Day Action Plan
행동을 추상적으로 쓰지 않는다.

나쁜 예:
> 직무역량을 강화한다.

좋은 예:
> 30일 안에 목표직무 채용공고 10건에서 반복되는 Tool·Task를 비교하고, 부족한 Excel/SQL 분석 실습 결과물 1건을 완성한다.

### 110–118분 | 최종 검증
학생이 직접 체크한다.
- Application Gate 원문대조
- 실제 Target JD 기반
- 모든 포함자료의 Fact Check
- Resume / Cover / Interview 일관성
- Final Ready와 Draft/GAP 구분

### 118–120분 | 저장 / PDF
Jobfit에서 최종 저장 후 인쇄/PDF 저장.

## AI 사용범위
AI는 다음을 도울 수 있다.
- 포트폴리오 순서 정리
- 중복내용 표시
- 제목 간결화
- GAP를 행동계획으로 구체화하기 위한 질문
- 지원자료 최종 검토 질문

AI는 다음을 하지 않는다.
- 빠진 Evidence 생성
- Draft를 사실처럼 보완
- Application Gate 미충족을 임의로 무시
- 숫자·성과 추가
- 학생이 실제로 설명할 수 없는 Positioning 생성

## Final Ready System 기준
Jobfit의 기본 System Readiness는 최소한 다음이 연결돼야 한다.
- Target JD 존재
- Application Gate 검토 완료 및 확인필요/미충족 없음
- Verified Career Asset 1개 이상
- Final Ready Resume 1개 이상
- Final Ready Cover Letter 1개 이상
- Ready Interview Evidence 1개 이상

단, 이 기준은 합격가능성 평가가 아니다. **자료가 서로 연결·검증되어 있다는 최소 운영 기준**이다.

Critical GAP가 남아 있을 수 있으며 학생은 이를 Portfolio에 명시한다.

## 기말평가 원칙
디자인보다 다음을 우선한다.
1. **직무·JD 적합성** — 실제 공고를 기준으로 했는가
2. **Evidence 품질** — 주장에 실제 행동·결과 근거가 있는가
3. **사실 일관성** — 서류와 면접의 역할·기간·수치가 일치하는가
4. **지원 활용성** — 실제 제출 가능한 수준인가
5. **GAP 현실성** — 부족한 점을 숨기지 않고 보완계획으로 연결했는가
6. **가독성·디자인** — 내용을 방해하지 않는가

예쁜 Portfolio지만 Evidence가 약하면 높은 평가를 주지 않는다.

## 15주차 / 기말 제출
15주차 보강·영상대체 기간에는 큰 내용을 새로 만들지 않고 누락·오류를 수정한다.

16주차 기말평가에서는 **수업시간에 완성한 Job Application Portfolio 최종본**을 제출한다.
