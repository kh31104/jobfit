# Week 14 — AI Job Application Portfolio Workshop

## Position in course
Jobfit STEP 13. Students assemble semester outputs into one job-ready application package during class.

## Learning outcomes
Students can:
1. assemble accumulated Jobfit data instead of starting from a blank document;
2. select only evidence relevant to one Target JD;
3. present a coherent story across career profile, job/company analysis, application documents and interview evidence;
4. identify remaining gaps;
5. create 30-day and 90-day action plans.

## Portfolio structure
1. WHO I AM — Career DNA + evidence-based competencies
2. TARGET JOB — Target Job and Job Deep Dive
3. INDUSTRY & COMPANY — target context
4. TARGET JD — actual posting and key requirements
5. CAREER ASSETS — strongest evidence
6. RESUME — final bullets / experience description
7. COVER LETTER — Human-First final version
8. INTERVIEW EVIDENCE — personal question bank and answer evidence
9. CAREER FIT — current job–industry–company direction
10. GAP & ACTION PLAN — key gaps, 30-day and 90-day actions

## Workshop flow
### 1. Auto-assemble
Open STEP 13 and load all existing outputs.

### 2. Remove irrelevant content
Not every semester artifact must appear in the final package. Keep the evidence that supports the selected JD.

### 3. AI editing support
AI may help with ordering, concise headings and duplication removal. It may not invent missing portfolio evidence.

### 4. Final verification
Students confirm:
- actual JD used;
- all facts checked;
- document/interview consistency;
- remaining gaps explicitly identified.

### 5. Save / print to PDF
Use the Jobfit print view to save a clean PDF if needed. The final grading submission format can be set by the instructor.

## Final assessment principle
A beautiful portfolio with weak evidence is not a strong submission. Priority is:
1. job relevance;
2. evidence quality;
3. factual consistency;
4. application readiness;
5. readability/design.

## Week 15 / final submission
Week 15 is a revision/buffer period if the academic calendar requires it. The final examination submission is the completed Job Application Portfolio.
